1. Execute the query - note how parent object field is referenced - College__r.Name
SELECT Id, Name, Roll_Number__c, Branch__c, College__r.Name FROM Student__c 

Debug - Open execute anonymous window:

2a. Convert the above query into apex language with standard object:
List<Student__c> students = [select name, roll_number__c, branch__c, college__r.name from student__c];
for (Student__c student: students) {
    system.debug('Student name: ' +student.name + ' Roll No: ' +student.roll_number__c + ' Branch: '+student.branch__c + ' College Name: ' +student.college__r.name);
}
Execute - Debug only to see above debug stmts

2b. Convert the above query into apex language with Sobject:
List<SObject> students = [select name, roll_number__c, branch__c, college__r.name from student__c];
for (SObject student: students) {
    system.debug('Student name: ' +student.get('name') + ' Roll No: ' +student.get('roll_number__c') + ' Branch: '+student.get('branch__c') + ' College Name: ' +student.getSObject('college__r').get('name'));
}
