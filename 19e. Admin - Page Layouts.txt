Common Reasons You Can Still Edit

1. You're Using Quick Edit/Inline Editing

If you're editing directly from the list view (clicking the pencil icon on a field)
Page layout read-only only applies to the record detail/edit page, not list views
Solution: Go to the actual record page and click "Edit" button to see read-only enforcement

2. You're an Admin or System Admin Profile

System Administrators often bypass certain UI restrictions
Page layout read-only is more of a UI convenience than hard security
Check: Are you logged in as a System Administrator?

3. Field-Level Security Overrides

If the field has "Read" and "Edit" permissions in your profile's field-level security, you can edit it
Page layout read-only is the weaker restriction
Field-level security (profile) > Page layout settings

4. You're Editing via Different Method
Page layout read-only doesn't prevent editing through:

API calls
Data Loader
Apex code/triggers
Process Builder/Flow
Mobile app (sometimes)
